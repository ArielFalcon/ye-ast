# Reference Identity and Local Bindings Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task-by-task. Checkboxes are pending. This is a bounded plan; coordinate interfaces with the receiver/DI work before editing shared files.

**Goal:** Retire only the exact unresolved occurrence supported by a proof and exclude a narrowly proven callback-parameter homonym from removed-declaration candidates.

**Architecture:** Preserve graph occurrence coordinates through application proofs and domain decisions; do not change public fact locations. The TypeScript adapter answers a consumer-owned syntax question, application carries evidence, and domain decides whether an exclusion applies. Preserve the walk and entrypoint join contracts.

**Tech Stack:** TypeScript 6 public syntax API, Node test runner, existing codegraph and module resolver; no new dependencies or Program.

**Spec:** `../specs/2026-11-04-symbol-proof-improvements-design.md`. Architectural references: `docs/architecture/rfc/0001-architecture-and-layers.md`, `0010-impact-queries.md` (removed candidates and entrypoint join), `0016-type-resolution.md` (S7, S12), `docs/architecture/adr/0019-cuts-retired-on-a-proven-external-target.md`. This plan narrows ADR-0019's reference identity; it does not change its external-proof standard.

## Global constraints

- Source of truth is the head snapshot, including unsaved/exported source text; missing or unreadable inputs prove nothing. Keep Java conservative.
- No new inferred call edges, general type inference, private binder API, dependency, public fact field, or changes to symbol/entrypoint selection. Retire only a proven occurrence; keep existing deterministic output ordering and line-based `Cut.at` rendering. Public diagnostics stay as they are; do not add an observability subsystem.
- Column is **optional on internal consumers** for old fixtures/other producers, but graph's `GraphUnresolvedReference.column` stays required. Missing, invalid, unverified or ambiguous coordinates never create retirement or exclusion proofs. This may retain extra cuts. Do not fall back to line/name keys.
- Preserve cancellation/deadline behavior: no new background work, no swallowed abort; parse lazily once per requested file per snapshot, batch sites, discard trees after the batch. Do not introduce a separate long-lived cache.

## Observed coordinate characterization (completed investigation)

The lead ran the real pinned codegraph adapter on `calls.ts`: an indented bare call is reported at raw column 2; after `é😀`, the first `missing()` is raw column 20 (UTF-16), while the UTF-8 byte prefix is 23. Two same-line calls are reported at columns 20 and 31. `inject(Svc).hit()` produces distinct `inject` and `inject().hit` rows at the same column 2. Evidence: `docs/explainer/audits/2026-11-04-name-webapp-cuts/symbol-planning/coordinates/evidence.json`. Therefore use **1-based lines / 0-based UTF-16 graph columns**, normalize to the existing **1-based UTF-16 TypeResolution** at its call boundary, and preserve full name/kind identity. The current `settledReferences` passes the raw column unchanged, while `type-resolution.adapter.ts:147` subtracts one: this is a concrete coordinate mismatch to regress and correct. The plan is now executable for these characterized source kinds; it does not infer column conventions of another producer.

## Review focus

- Two identical roots on one line, one shadowed: only the individually proven occurrence may retire (Tasks 1–2).
- Nested calls sharing a coordinate but having different names must remain independent; indistinguishable full-tuple/syntax matches remain unknown (Task 1).
- Missing, stale, out-of-range or wrong-base coordinate: unknown, no proof (Tasks 1–2).
- Parameter shadowing, destructuring, nested functions and same-file declarations: exclude only the supported unique bare parameter occurrence and preserve all other candidates (Task 2).
- A settled target not actually reached or not joined to its caller cannot silently remove a cut (Task 1).

## Explicit exclusions and risks

No general lexical binder, alias/value-flow or runtime callback target, module export analysis, arbitrary local declarations, destructuring, qualified receiver inference, Java proof, or scope-aware relaxation of ambient/import shadowing. Unmatched or indistinguishable source occurrences, malformed files and unsupported scope syntax stay unknown. An indirect callback might receive a removed function as a value; this plan only rules out direct binding to the removed declaration and must not be represented as whole-program runtime independence. The proof assumes the index uses the same snapshot bytes; a mismatch stays unknown. Public line-only cut rendering cannot distinguish surviving occurrences but must never hide one.
